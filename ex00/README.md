# Personal Portfolio

## About

This project is a personal portfolio built using HTML, CSS, and JavaScript.
It brings together the main concepts I practised in my previous projects.

## Features

- About Me section with a profile photo
- Skills grid
- Showcase of Projects 00 through 03
- Interests section
- Contact form
- Interactive light and dark theme switcher
- Responsive layout for smaller screens

## Technologies

- HTML5 for the page structure
- CSS3 for layout, colours, and responsive design
- JavaScript for the theme switcher and form interaction
- Git and GitHub for version control and sharing the project

## How to Run

Open `index.html` in a web browser.

Make sure the profile photo is saved as `assets/profile.jpg`.

## What I Learned

This project helped me combine HTML, CSS, and JavaScript in one website.
I practised semantic HTML, Flexbox, media queries, DOM manipulation,
event listeners, and responsive design.
